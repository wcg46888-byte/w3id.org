# 游戏连点器（Android）

一个安卓平台的屏幕连点器（Auto Clicker）。可以在屏幕上设置**多个点击位置**，按编号顺序、以设定的时间间隔**循环自动点按**，效果类似电脑上的鼠标宏。基于系统**无障碍服务**的手势注入实现，**无需 Root**。

## 功能

- ➕ 添加任意数量的点击位置，编号圆点可自由拖动到屏幕任意处
- 🔁 按 1 → 2 → 3 → … 的顺序循环点击
- ⚙ 可设置：
  - **点击间隔**（毫秒）：两次点击之间的等待时间
  - **按压时长**（毫秒）：每次点按屏幕的按住时间
  - **随机抖动**（±毫秒）：给间隔加入随机波动，使点击节奏不那么机械
  - **循环轮数**：点完一整套算一轮，0 表示无限循环
- 💾 点位和设置自动保存，下次打开面板自动恢复
- 运行时点位标记自动变为半透明且**可穿透**，注入的点击会落到下层的游戏上

## 构建方法

### 方式一：不用 Android Studio（Linux 一键打包）

```bash
sudo apt-get install -y aapt zipalign apksigner dalvik-exchange default-jdk-headless
./build-apk.sh
# APK 输出位置: build/AutoClicker-debug.apk
```

脚本会自动下载 android.jar 和 Kotlin 编译器，用 aapt + dx + apksigner 完成编译、打包和签名，全程无需 Android Studio / Gradle / Android SDK。

### 方式二：Android Studio

用 **Android Studio** 打开本目录（`game-auto-clicker/`），等待 Gradle 同步完成后直接运行，或执行：

```bash
./gradlew assembleDebug
# APK 输出位置: app/build/outputs/apk/debug/app-debug.apk
```

- 最低支持 Android 7.0（API 24，`dispatchGesture` 手势注入的最低版本要求）
- 无任何第三方依赖，纯 Kotlin + Android 框架 API

## 使用步骤

1. 安装并打开应用，点击「**① 打开无障碍设置**」，在系统无障碍设置中找到「游戏连点器（点击服务）」并开启
2. 返回应用，点击「**② 显示 / 隐藏悬浮面板**」（开启无障碍服务后面板也会自动出现）
3. 切换到游戏，通过悬浮面板操作：
   | 按钮 | 作用 |
   |------|------|
   | ⠿ | 按住拖动整个面板 |
   | ➕ | 添加一个点击位置（拖动编号圆点到目标处） |
   | ➖ | 删除最后一个点位 |
   | ▶ / ⏸ | 开始 / 停止连点 |
   | ⚙ | 打开设置（间隔 / 按压时长 / 抖动 / 轮数） |
   | ✕ | 收起面板和所有点位（位置仍会保存） |

## 注意事项

- ⚠️ **部分网络游戏的用户协议禁止使用自动点击类工具**，检测到后可能封号，请仅在单机游戏或允许的场景下使用，风险自负。
- 部分国产系统（MIUI、EMUI 等）会自动清理后台并关闭无障碍服务，建议在系统设置中给本应用加锁 / 允许自启动。
- 本应用不联网、不读取屏幕内容，仅使用手势注入能力。
